构造 17、257 和 65537 边形

经典地，能够用尺规作图构造的正多边形仅有 3、4、5 或 15 边形，以及这些边数乘以 2 的幂（因为二等分很容易）。卡尔·弗里德里希·高斯于 1801 年发表了一个证明，表明边数为素数且形如 2^2^m + 1（称为费马素数）的正多边形可以被构造，并声称他证明了只有这些可以被构造（以及由单个费马素数的幂与 2 的幂相乘所得的构造）。Wantzel 后来发表了一个完整的证明。已知的费马素数仅有 N = 3、5、17、257 和 65537。更多历史请参见 Wikipedia。

核心思想是将正多边形在单位圆上的顶点视为复数，即 zN = 1 的解。因此这些顶点就是"N 次单位根"。高斯证明了某些单位根的和可以用其他和通过二次方程递归求解，最终归结为一对共轭根的和，其一半给出了一个根的实部。由于二次方程可以用尺规作图求解，因此构造是可以实现的。

算法：

  1. 找到一个生成 ZN 乘法群的整数 K。对于 N = 5、17、257、65537，K = 3 恰好适用，因此我们直接使用它。
  2. 列出 K 模 N 的幂次，例如对于 N = 17，我们有 1、3、9、10、……。该列表有 N-1 个元素，因为 0 不在乘法群中不会出现。按此顺序列出 N-1 个单位根（省略 1）。
  3. 设 S(m,i) 为从列表中第 i 个开始、每隔 m 个取一个的根的和。我们仅使用 m 为 2 的幂的情况。注意 S(1,0) = -1，因为所有 N 个根之和为 0（zN - 1 = 0 中 zN-1 的系数），且 1 被省略。
  4. 事实证明，S(2*m,i)*S(2*m,i+m) 是 S(m,j) 及更低阶项的整数系数线性组合。同时，S(2*m,j)+S(2*m,j+m) = S(m,j)。从 S(1,0) = -1 开始，我们可以递归地通过二次方程求解所有 S(m,i)。
  5. 当 m = (N-1)/2 时，S(m,i) 恰好是两个共轭根的和，因此 S((N-1)/2,i) 就是这两个根（设为 U 和 V）的 x 坐标。
  6. 任意两个根之间的弦（例如 1 和 U，或 U 和 V）可以用来在单位圆上标出所有 N 个顶点。
关键的一步是在第 4 步中找到线性组合。出于兴趣，我编写了一个程序来寻找这种组合。所使用的方法是将乘积写成根的符号和，然后用高斯消元法求系数；幸运的是，消元矩阵一开始就很稀疏，并且随着求解的进行越来越稀疏。即使是 65537 边形，使用稀疏矩阵技术，整个消元过程不到 10 分钟，占用不到 60 MB 内存。输出是一个 Mathematica 文件，其中包含一系列二次公式，最终得到所需的值。
