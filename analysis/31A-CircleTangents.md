# 两圆的外公切线 —— 数学分析

## 1. 问题描述

给定平面上两个不相交的圆：

$$\omega_1: \text{圆心 } A,\; \text{半径 } r_1 \qquad \omega_2: \text{圆心 } B,\; \text{半径 } r_2$$

**外公切线**是指一条与两个圆都相切、且两个切点位于连心线 $AB$ 同侧的直线。本作图要求使用尺规作图法，构造出两圆的全部外公切线。

---

## 2. 数学模型

### 2.1 外公切线的定义

设直线 $\ell$ 与 $\omega_1$ 切于点 $G$，与 $\omega_2$ 切于点 $K$。若 $G$ 和 $K$ 位于直线 $AB$ 的**同一侧**，则 $\ell$ 称为两圆的一条**外公切线**。

由对称性，若存在一条外公切线，则在 $AB$ 的另一侧必存在第二条外公切线。因此外公切线的数目为 0 或 2（退化情形下可能为 1）。

### 2.2 外位似中心（External Center of Similitude）

**定义.** 点 $E$ 称为 $\omega_1$ 和 $\omega_2$ 的**外位似中心**，若 $E$ 在直线 $AB$ 上，且满足：

$$\frac{EA}{EB} = \frac{r_1}{r_2}$$

其中 $E$ 在线段 $AB$ 的外部（即 $A$、$B$ 在 $E$ 的同侧）。等价地，$E$ 以比例 $r_1 : r_2$ 外分线段 $AB$。

**关键性质.** 若 $E$ 是外位似中心，则从 $E$ 向 $\omega_1$ 所作的切线，同时也是 $\omega_2$ 的切线。

**证明思路.** 设 $\ell$ 是从 $E$ 向 $\omega_1$ 所作的切线，切点为 $G$，即 $EG \perp AG$。考虑以 $E$ 为位似中心、比例为 $r_2/r_1$ 的位似变换 $\mathcal{H}$：

$$\mathcal{H}: P \mapsto E + \frac{r_2}{r_1}(P - E)$$

此变换将 $\omega_1$ 映为 $\omega_2$（因为 $\mathcal{H}(A) = B$，且半径 $r_1 \mapsto r_2$），将切线 $\ell$ 映为自身（因为 $\ell$ 过位似中心 $E$），将切点 $G$ 映为 $\ell$ 上某点 $K \in \omega_2$。由于位似变换保持角度，$EK \perp BK$，故 $\ell$ 与 $\omega_2$ 也相切于 $K$。

---

## 3. 构造步骤详细推导

以下逐步分析源码中的构造过程。

**输入.** 两点 $A$、$B$ 及两个圆 $\omega_1(A, r_1)$、$\omega_2(B, r_2)$。

### 步骤 1：射线 $AB$

过 $A$、$B$ 作射线 $\overrightarrow{AB}$，确定两圆心的方向。

```javascript
L3.x1 = a.x; L3.y1 = a.y; L3.x2 = b.x; L3.y2 = b.y;
```

### 步骤 2：过 $A$ 和 $B$ 作 $AB$ 的垂线

- $L_1$：过点 $A$，垂直于 $AB$。
- $L_2$：过点 $B$，垂直于 $AB$。

```javascript
perp_to_line(a, b, L1);  // L1 ⊥ AB, 过 A
perp_to_line(b, a, L2);  // L2 ⊥ AB, 过 B
```

若 $AB$ 为水平线，则 $L_1$、$L_2$ 为竖直线，分别过 $A$ 和 $B$。

### 步骤 3：取两圆的同侧顶点 $C$、$D$

- $C$：$L_1$ 与 $\omega_1$ 的交点中，$y$ 坐标较小者（取"下方"顶点）。
- $D$：$L_2$ 与 $\omega_2$ 的交点中，$y$ 坐标较小者。

```javascript
line_circle(L1, c1, c, m); if (m.y < c.y) { c.x = m.x; c.y = m.y; }
line_circle(L2, c2, d, m); if (m.y < d.y) { d.x = m.x; d.y = m.y; }
```

几何意义：$L_1 \perp AB$ 过 $A$，因此 $L_1 \cap \omega_1$ 的两个交点恰好是 $\omega_1$ 在 $AB$ 方向上的两个极值点（"最高点"和"最低点"）。选择同侧的点 $C$、$D$ 后，$AC = r_1$，$BD = r_2$，且 $AC \parallel BD$（都垂直于 $AB$），因此 $AC$ 和 $BD$ 方向相同。

### 步骤 4：射线 $CD$ 与 $AB$ 的交点 $E$

连接 $C$、$D$ 作射线 $CD$，与直线 $AB$（即 $L_3$）交于点 $E$。

```javascript
L4.x1 = c.x; L4.y1 = c.y; L4.x2 = d.x; L4.y2 = d.y;
line_line(L3, L4, e);
```

**定理.** 此交点 $E$ 即为 $\omega_1$、$\omega_2$ 的**外位似中心**。

**证明.** 由于 $AC \perp AB$、$BD \perp AB$，故 $AC \parallel BD$。在 $\triangle EAC$ 和 $\triangle EBD$ 中：

- $\angle EAC = \angle EBD = 90^\circ$（$AC \perp AB$，$BD \perp AB$）
- $\angle AEC = \angle BED$（对顶角）

因此 $\triangle EAC \sim \triangle EBD$（AA 相似），得到：

$$\frac{EA}{EB} = \frac{AC}{BD} = \frac{r_1}{r_2}$$

这正是外位似中心的定义条件。$\blacksquare$

### 步骤 5：$AE$ 的中点 $F$

```javascript
f.x = (a.x + e.x) / 2; f.y = (a.y + e.y) / 2;
```

### 步骤 6：以 $F$ 为圆心、$|FA|$ 为半径作圆

```javascript
c3.x = f.x; c3.y = f.y; c3.r = dist(f, a);
```

此圆的半径为 $|FA| = |AE|/2$，圆心为 $AE$ 的中点 $F$。因此 **$AE$ 是此圆的直径**。

我们将此圆记为 $\Omega$。

### 步骤 7：$\Omega$ 与 $\omega_1$ 的交点 $G$、$H$

```javascript
circle_circle(c1, c3, g, h);
```

$\Omega \cap \omega_1 = \{G, H\}$。

### 步骤 8：切线 $EG$、$EH$

连接 $E$ 与 $G$、$E$ 与 $H$，得到两条外公切线。

```javascript
draw_line(e, g);
draw_line(e, h);
```

## 4. 正确性证明

**定理.** 直线 $EG$ 和 $EH$ 是 $\omega_1$ 和 $\omega_2$ 的两条外公切线。

### 4.1 $EG$ 与 $\omega_1$ 相切于 $G$

由于 $AE$ 是 $\Omega$ 的直径，$G$ 在 $\Omega$ 上，由**泰勒斯定理（Thales' Theorem）**：

$$\angle AGE = 90°$$

即 $EG \perp AG$。

又因为 $A$ 是 $\omega_1$ 的圆心，$G$ 在 $\omega_1$ 上，$EG \perp AG$ 意味着 $EG$ 恰好是 $\omega_1$ 在点 $G$ 处的切线。

同理，$EH$ 与 $\omega_1$ 相切于 $H$。

### 4.2 $EG$ 与 $\omega_2$ 相切

设 $EG$ 与 $\omega_2$ 交于点 $K$（或与 $\omega_2$ 相切于点 $K$）。由外位似中心 $E$ 的位似变换 $\mathcal{H}$（比例 $k = r_2/r_1$）：

$$\mathcal{H}(G) = K, \quad \mathcal{H}(A) = B, \quad \mathcal{H}(\omega_1) = \omega_2$$

由于位似变换保持角度：

$$\angle EGA = 90° \implies \angle EKB = 90°$$

因此 $EK \perp BK$，即 $EG$（即直线 $EK$）在点 $K$ 处与 $\omega_2$ 相切。

### 4.3 外公切线的性质

由于 $G$、$H$ 位于 $AB$ 的同一侧（$\Omega$ 与 $\omega_1$ 的两个交点关于 $AB$ 对称，分别在 $AB$ 的上方和下方），$EG$ 和 $EH$ 分别是 $AB$ 上方和下方的两条外公切线。

综上，$EG$ 和 $EH$ 是两圆的两条外公切线。$\blacksquare$

---

## 5. 唯一性与存在性分析

设 $d = |AB|$ 为两圆心距离。外公切线的存在性取决于 $d$、$r_1$、$r_2$ 的关系。

### 5.1 一般情形：$r_1 \neq r_2$

| 条件 | 外公切线数目 | 说明 |
|------|:---:|------|
| $d > r_1 + r_2$ | **2** | 两圆外离，标准情形 |
| $d = r_1 + r_2$ | **2** | 两圆外切，外公切线仍存在 |
| $|r_1 - r_2| < d < r_1 + r_2$ | **2** | 两圆相交，外公切线仍存在 |
| $d = |r_1 - r_2|$ | **1** | 两圆内切，外公切线退化为一条 |
| $0 < d < |r_1 - r_2|$ | **0** | 一圆完全包含另一圆 |
| $d = 0$ | **0** | 同心圆，不存在外公切线 |

### 5.2 特殊情形：$r_1 = r_2$

当两圆半径相等时，外位似中心 $E$ 在无穷远处。此时外公切线是两条平行于 $AB$ 的直线：

$$\ell_1: y = r_1, \qquad \ell_2: y = -r_1$$

（在 $AB$ 为水平线的坐标系下）

源码中的构造无法直接处理此情形（$E$ 不存在），需要单独处理。

### 5.3 构造中各步骤的存在性条件

| 步骤 | 所需条件 | 不满足时的含义 |
|------|---------|--------------|
| 步骤 3: $L_1 \cap \omega_1$ | 恒成立 | $L_1$ 过圆心 $A$，必与 $\omega_1$ 相交 |
| 步骤 3: $L_2 \cap \omega_2$ | 恒成立 | $L_2$ 过圆心 $B$，必与 $\omega_2$ 相交 |
| 步骤 4: $CD \cap AB$ | $CD \nparallel AB$ | 当 $r_1 = r_2$ 时 $CD \parallel AB$，无交点 |
| 步骤 7: $\Omega \cap \omega_1$ | $|r_1 - r_2| \leq d_{AE}/2 \leq r_1 + d_{AE}/2$ | 恒成立（见下文） |

**步骤 7 存在性的补充论证.** $\Omega$ 的半径为 $R_\Omega = |AE|/2$，圆心 $F$ 到 $A$ 的距离为 $|AE|/2$。因此 $A$ 在 $\Omega$ 上。由于 $A$ 也在 $\omega_1$ 上，$\Omega$ 与 $\omega_1$ 至少共享点 $A$。实际上，只要 $r_1 > 0$，$A$ 处两圆的切线方向不同（$\Omega$ 在 $A$ 处的切线方向与 $\omega_1$ 在 $A$ 处的切线方向不重合，因为 $AE$ 不是 $\omega_1$ 的直径），因此两圆在 $A$ 处横截相交，必有另一交点 $G$（或 $H$）。

> **注.** 严格来说，当 $E$ 恰在 $\omega_1$ 的圆周上时，$|AE| = r_1$，此时 $\Omega$ 与 $\omega_1$ 的关系需要特别分析。但这仅在特殊的退化位置出现，不影响一般性结论。

## 6. 数值验证

取默认参数进行具体计算：

$$A = (-1.7,\; 0), \quad B = (0.3,\; 0), \quad r_1 = 1.2, \quad r_2 = 0.65$$

### 6.1 基本量

$$d = |AB| = |0.3 - (-1.7)| = 2.0$$

$$r_1 + r_2 = 1.2 + 0.65 = 1.85 < 2.0 = d \quad \checkmark \text{（两圆外离）}$$

因此存在两条外公切线。

### 6.2 外位似中心 $E$

$E$ 在直线 $AB$（即 $x$ 轴）上，设 $E = (e, 0)$，满足：

$$\frac{EA}{EB} = \frac{r_1}{r_2} = \frac{1.2}{0.65} = \frac{24}{13}$$

外分条件：$E$ 在 $B$ 的外侧（$A$、$B$ 在 $E$ 同侧），即 $E$ 不在线段 $AB$ 上。

$$\frac{e - (-1.7)}{e - 0.3} = \frac{1.2}{0.65}$$

$$0.65(e + 1.7) = 1.2(e - 0.3)$$

$$0.65e + 1.105 = 1.2e - 0.36$$

$$1.465 = 0.55e$$

$$e = \frac{1.465}{0.55} = \frac{293}{110} \approx 2.6\overline{63}$$

因此：

$$E \approx (2.6\overline{63},\; 0)$$

验证：

$$EA = 2.663 + 1.7 = 4.363, \quad EB = 2.663 - 0.3 = 2.363$$

$$\frac{EA}{EB} = \frac{4.363}{2.363} \approx 1.847 \approx \frac{1.2}{0.65} \approx 1.846 \quad \checkmark$$

### 6.3 中点 $F$ 和圆 $\Omega$

$$F = \frac{A + E}{2} = \left(\frac{-1.7 + 2.663}{2},\; 0\right) = (0.4815,\; 0)$$

$$R_\Omega = |AF| = \frac{|AE|}{2} = \frac{4.363}{2} = 2.182$$

### 6.4 求交点 $G$、$H$

$\omega_1$ 的方程：

$$(x + 1.7)^2 + y^2 = 1.44$$

$\Omega$ 的方程：

$$(x - 0.4815)^2 + y^2 = 4.759$$

两式相减：

$$(x + 1.7)^2 - (x - 0.4815)^2 = 1.44 - 4.759$$

展开：

$$(x^2 + 3.4x + 2.89) - (x^2 - 0.963x + 0.2318) = -3.319$$

$$4.363x + 2.658 = -3.319$$

$$x = \frac{-3.319 - 2.658}{4.363} = \frac{-5.977}{4.363} \approx -1.3698$$

代入 $\omega_1$：

$$(-1.3698 + 1.7)^2 + y^2 = 1.44$$

$$(0.3302)^2 + y^2 = 1.44$$

$$0.1090 + y^2 = 1.44$$

$$y^2 = 1.3310$$

$$y \approx \pm 1.1537$$

因此：

$$G \approx (-1.370,\; 1.154), \qquad H \approx (-1.370,\; -1.154)$$

### 6.5 验证切线条件

验证 $EG \perp AG$：

$$\vec{AG} = G - A = (-1.370 + 1.7,\; 1.154 - 0) = (0.330,\; 1.154)$$

$$\vec{EG} = G - E = (-1.370 - 2.663,\; 1.154 - 0) = (-4.033,\; 1.154)$$

$$\vec{AG} \cdot \vec{EG} = (0.330)(-4.033) + (1.154)(1.154) = -1.331 + 1.331 = 0.000 \quad \checkmark$$

点积为零，$\angle AGE = 90°$，即 $EG$ 是 $\omega_1$ 在 $G$ 处的切线。

### 6.6 验证 $EG$ 也是 $\omega_2$ 的切线

$EG$ 的直线方程（参数形式）：从 $E = (2.663, 0)$ 沿方向 $(-4.033, 1.154)$。

$\omega_2$ 的方程：$(x - 0.3)^2 + y^2 = 0.4225$

点 $B = (0.3, 0)$ 到直线 $EG$ 的距离应等于 $r_2 = 0.65$。

直线 $EG$ 的方向向量为 $(-4.033, 1.154)$，法向量为 $(1.154, 4.033)$。直线过点 $E = (2.663, 0)$，方程为：

$$1.154(x - 2.663) + 4.033(y - 0) = 0$$

$$1.154x + 4.033y - 3.073 = 0$$

$B = (0.3, 0)$ 到此直线的距离：

$$d(B, EG) = \frac{|1.154 \times 0.3 + 4.033 \times 0 - 3.073|}{\sqrt{1.154^2 + 4.033^2}} = \frac{|0.346 - 3.073|}{\sqrt{1.331 + 16.265}} = \frac{2.727}{\sqrt{17.596}}$$

$$= \frac{2.727}{4.195} = 0.650 \approx 0.65 = r_2 \quad \checkmark$$

$EG$ 确实与 $\omega_2$ 相切。$\blacksquare$
