# 尺规作图 39：与三圆相切的圆（阿波罗尼奥斯问题）

## 数学分析

---

## 1. 问题描述

### 1.1 经典阿波罗尼奥斯问题

阿波罗尼奥斯问题（Apollonius Problem）是古希腊几何学家阿波罗尼奥斯（约公元前 262--190 年）提出的经典尺规作图问题：

> **给定三个圆 $\Gamma_1, \Gamma_2, \Gamma_3$，求作一个圆 $\mathcal{C}$，使得 $\mathcal{C}$ 与三个圆均相切。**

这是平面几何中最著名的作图问题之一，与"过三点作圆"（作图 12）并列为圆的基本构造问题。

### 1.2 本构造的已知条件

本作图（编号 39）的具体已知条件为：

| 对象 | 记号 | 默认参数 |
|------|------|----------|
| 第一圆 $\Gamma_1$ | 圆心 $L$，半径 $r_1 = \|LM\|$ | $L=(0.5,\,1.0)$，$M=(0.3,\,1.0)$，$r_1=0.2$ |
| 第二圆 $\Gamma_2$ | 圆心 $B$，半径 $r_2 = \|BC\|$ | $B=(0.5,\,-1.5)$，$C=(1.3,\,-1.5)$，$r_2=0.8$ |
| 第三圆 $\Gamma_3$ | 圆心 $O$，半径 $r_3 = \|AO\|$ | $O=(-2.3,\,-1.5)$，$A=(-2.3,\,-0.9)$，$r_3=0.6$ |

**求作：** 圆 $\mathcal{C}(X, R)$，使得：

1. $\mathcal{C}$ 与 $\Gamma_1(L, r_1)$ 相切；
2. $\mathcal{C}$ 与 $\Gamma_2(B, r_2)$ 相切；
3. $\mathcal{C}$ 与 $\Gamma_3(O, r_3)$ 相切。

其中 $A$ 是 $\Gamma_3$ 上的点（$r_3 = |AO|$），$C$ 是 $\Gamma_2$ 上确定半径的点（$r_2 = |BC|$），$M$ 是 $\Gamma_1$ 上确定半径的点（$r_1 = |LM|$）。所有蓝色点均可拖动。

### 1.3 核心思路

本构造采用 **扩张（expansion）** 加 **反演（inversion）** 的两阶段策略：

1. **扩张阶段：** 将三个圆的半径统一增加 $\delta$，使得 $\Gamma_2$ 和 $\Gamma_1$ 的扩张圆在一点 $F$ 处相交。$F$ 的选取利用了两圆心连线 $BL$ 与两圆的交点。
2. **反演阶段：** 以 $F$ 为反演中心，$\Gamma_2$ 和 $\Gamma_1$ 的扩张圆（均过 $F$）变为两条平行线，$\Gamma_3$ 的扩张圆（不过 $F$）变为另一个圆。简化后的问题为"与两条平行线及一个圆相切"，这是可解的。
3. **回代阶段：** 将简化问题的解反演回原平面，得到最终答案。

## 2. 数学模型

### 2.1 反演的基本理论

**定义 2.1.** 以点 $F$ 为反演中心、$\rho$ 为反演半径的**反演变换** $\mathcal{I}_F$ 定义为：

$$
\mathcal{I}_F(P) = P' = F + \frac{\rho^2}{|FP|^2}(P - F), \quad P \neq F
$$

反演满足 $|FP| \cdot |FP'| = \rho^2$，且 $F, P, P'$ 三点共线。

**定理 2.1（反演的保角性）.** 反演是保角变换（conformal map）：两曲线在交点处的夹角在反演下保持不变。

**推论 2.2.** 若两圆（或圆与直线）相切（夹角为零），则其反演像也相切。

**定理 2.3（反演对圆的作用）.** 设 $\mathcal{I}_F$ 为以 $F$ 为中心、$\rho$ 为半径的反演，则：

| 原像 | 条件 | 反演像 |
|------|------|--------|
| 过 $F$ 的圆 $\omega$ | 在 $F$ 处切线方向为 $\mathbf{v}$ | 方向为 $\mathbf{v}$ 的直线 |
| 过 $F$ 的直线 $\ell$ | — | $\ell$ 自身 |
| 不过 $F$ 的圆 $\omega$ | 圆心 $C_\omega$，半径 $r_\omega$ | 不过 $F$ 的圆 $\omega'$ |
| 不过 $F$ 的直线 $\ell$ | — | 过 $F$ 的圆 |

### 2.2 圆的扩张技巧

**定义 2.2.** 给定正实数 $\delta$（扩张量），对圆 $\Gamma(C, r)$ 的**扩张**定义为：

$$
\Gamma_{\text{exp}} = (C,\; r + \delta)
$$

即圆心不变，半径增加 $\delta$。

**引理 2.4（扩张保持外切）.** 若圆 $\mathcal{C}(X, R)$ 与 $\Gamma_i(C_i, r_i)$（$i = 1, 2, 3$）均外切，即

$$
|XC_i| = R + r_i, \quad i = 1, 2, 3
$$

则扩张后的圆 $\mathcal{C}_{\text{exp}}(X, R+\delta)$ 与 $\Gamma_{i,\text{exp}}(C_i, r_i+\delta)$ 也外切：

$$
|XC_i| = (R + \delta) + (r_i + \delta) - 2\delta = R + r_i \quad \checkmark
$$

**证明：** 外切条件 $|XC_i| = R + r_i$ 等价于 $|XC_i| = (R+\delta) + (r_i+\delta) - 2\delta$。由于中心距 $|XC_i|$ 在扩张中不变，而扩张后各半径增加 $\delta$，故切触关系在同增 $\delta$ 后保持。$\square$

### 2.3 反演中心的选取策略

本构造的核心创新在于反演中心 $F$ 的选取。设 $B, L$ 为两圆 $\Gamma_2, \Gamma_1$ 的圆心，直线 $BL$ 与两圆分别交于 $E$ 和 $D$。

**定义 2.3.** 令

$$
F = \text{midpoint}(D, E)
$$

**引理 2.5.** 设 $\delta = |EF| = |DF|$（因为 $F$ 是 $DE$ 中点），则扩张圆

$$
\Gamma_{2,\text{exp}}(B, r_2 + \delta) \quad \text{和} \quad \Gamma_{1,\text{exp}}(L, r_1 + \delta)
$$

均经过 $F$。

**证明：**

由构造，$E \in \Gamma_2 \cap BL$，故 $|BE| = r_2$。由于 $F$ 在线段 $DE$ 上且 $D, E$ 在直线 $BL$ 上，$F$ 也在 $BL$ 上。故

$$
|BF| = |BE| + |EF| = r_2 + \delta
$$

（此处 $F$ 在 $B$ 和 $E$ 的延长方向上，取决于 $D, E$ 的位置关系。由代码中 swap 的条件 `dist(d,b) > dist(f,b)` 保证 $F$ 在 $B$ 和 $D$ 之间。）因此 $F \in \Gamma_{2,\text{exp}}$。

同理，$D \in \Gamma_1 \cap BL$，$|LD| = r_1$，$|LF| = |LD| + |DF| = r_1 + \delta$（由 swap 条件 `dist(e,l) > dist(f,l)` 保证 $F$ 在 $L$ 和 $E$ 之间），故 $F \in \Gamma_{1,\text{exp}}$。$\square$

### 2.4 反演后变为平行线

**定理 2.6.** 以 $F$ 为反演中心，$\Gamma_{2,\text{exp}}$ 和 $\Gamma_{1,\text{exp}}$ 均过 $F$，且它们的圆心 $B, L$ 与 $F$ 共线（$B, F, L$ 都在直线 $BL$ 上）。因此：

1. $\Gamma_{2,\text{exp}}$ 的反演像是直线 $\ell_2$，方向垂直于 $BF$。
2. $\Gamma_{1,\text{exp}}$ 的反演像是直线 $\ell_1$，方向垂直于 $LF$。
3. 由于 $B, F, L$ 共线，$\ell_2 \parallel \ell_1$。

**证明：**

由定理 2.3，过反演中心的圆变为直线，该直线垂直于圆心与反演中心的连线。

$\Gamma_{2,\text{exp}}$ 的圆心为 $B$，过 $F$，故其反演像 $\ell_2$ 垂直于 $BF$。同理 $\Gamma_{1,\text{exp}}$ 的反演像 $\ell_1$ 垂直于 $LF$。

由于 $B, F, L$ 共线（均在直线 $BL$ 上），$BF$ 和 $LF$ 同向，故 $\ell_2 \parallel \ell_1$。$\square$

**注记：** 与 37 号和 38 号作图不同，本构造中没有预先给定的直线，而是利用两圆心的连线 $BL$ 作为"广义直线"。反演后，两个过 $F$ 的扩张圆变为平行线，这与 37/38 号中"直线与扩张圆在 $F$ 处相切 $\Rightarrow$ 反演后变为平行线"的机制本质相同。

### 2.5 第三圆的反演像

$\Gamma_{3,\text{exp}}(O, r_3 + \delta)$ 不经过反演中心 $F$（一般情形下 $|FO| \neq r_3 + \delta$），因此其反演像 $\Gamma_3'$ 是一个不过 $F$ 的圆。

$\Gamma_3'$ 的圆心和半径需要通过 $F$ 射线上的两个特殊点来确定（详见步骤推导）。

### 2.6 简化后的问题

**定理 2.7.** 反演后，原问题转化为：

> 在反演平面中，求圆 $\mathcal{C}'$，使得 $\mathcal{C}'$ 与两条平行线 $\ell_1, \ell_2$ 及圆 $\Gamma_3'$ 均相切。

与 $\ell_1, \ell_2$ 均相切的圆的性质：

**引理 2.8.** 设 $\ell_1, \ell_2$ 为两条平行线，间距为 $h$。若圆 $\omega$ 与 $\ell_1, \ell_2$ 均相切，则 $\omega$ 的半径必为 $h/2$，圆心必在 $\ell_1, \ell_2$ 的**中线** $m$ 上（$m$ 到 $\ell_1, \ell_2$ 的距离均为 $h/2$）。

**证明：** 设 $\omega$ 的圆心为 $S$，半径为 $\rho$。与 $\ell_1$ 相切要求 $d(S, \ell_1) = \rho$；与 $\ell_2$ 相切要求 $d(S, \ell_2) = \rho$。两式相减得 $d(S, \ell_1) = d(S, \ell_2)$，故 $S$ 在中线 $m$ 上。两式相加得 $d(S, \ell_1) + d(S, \ell_2) = h$，即 $2\rho = h$，故 $\rho = h/2$。$\square$

因此，简化问题进一步化为：**在中线 $m$ 上找点 $S$，使以 $S$ 为圆心、$h/2$ 为半径的圆与 $\Gamma_3'$ 相切。**

设 $\Gamma_3'$ 的圆心为 $R$，半径为 $r_3'$。外切条件为：

$$
|SR| = \frac{h}{2} + r_3'
$$

这是"求中线 $m$ 与以 $R$ 为圆心、$h/2 + r_3'$ 为半径的圆的交点"，最多有两个解。

## 3. 构造步骤详细推导

### 步骤 1：连接圆心，求交点 $D, E$，构造扩张量

**尺规操作：** 过圆心 $B=(0.5,-1.5)$ 和 $L=(0.5,1.0)$ 作直线 $BL$。在默认参数下，$BL$ 为竖直线 $x=0.5$。

**$D$ 的确定：** $BL$ 与 $\Gamma_1$ 的交点中，取距 $L$ 较远者（经 swap 保证）。

$$
\Gamma_1 \cap BL: \quad (0.5)^2 + (y-1.0)^2 = 0.04
$$

$$
(y-1.0)^2 = 0.04 \implies y = 1.2 \;\text{或}\; 0.8
$$

$|EL| = |(0.5,0.8)-(0.5,1.0)| = 0.2 = r_1$，$|FL| = |(0.5,1.2)-(0.5,1.0)| = 0.2 = r_1$。
swap 保证 $|DB| > |FB|$（见源码注释），故：

$$
D = (0.5,\, 1.2), \quad E = (0.5,\, 0.8)
$$

（默认参数下 $B, L$ 共竖线，swap 不影响，因为 $|DB|=2.7 > |EB|=2.3$。）

**$F$ 的确定：** $F$ 为 $DE$ 的中点：

$$
F = \left(\frac{0.5+0.5}{2},\, \frac{1.2+0.8}{2}\right) = (0.5,\, 1.0)
$$

即 $F$ 与 $L$ 重合！（在默认参数的对称情况下。）

**扩张量：**

$$
\delta = |EF| = |DF| = 0.2
$$

**几何意义：** $BL$ 连接两圆心，与 $\Gamma_1$ 交于 $D$ 和 $E$。$F$ 为 $DE$ 中点。$|EF| = |DF| = \delta$ 是统一扩张量。

### 步骤 2：构造扩张圆 $\Gamma_{2,\text{exp}}$（circle2）和 $\Gamma_{1,\text{exp}}$（circle22）

$$
\Gamma_{2,\text{exp}}:\; \text{圆心 } B=(0.5,-1.5),\; \text{半径 } |BF| = 2.5
$$

$$
\Gamma_{1,\text{exp}}:\; \text{圆心 } L=(0.5,1.0),\; \text{半径 } |LF| = 0.0
$$

验证：$|BF| = |(0, -2.5)| = 2.5 = r_2 + \delta = 0.8 + 0.2 + 1.5 = 2.5$... 

实际上 $|BF| = |(0.5,-1.5)-(0.5,1.0)| = 2.5$，而 $r_2 + \delta = 0.8 + 0.2 = 1.0$。这说明 $|BF| \neq r_2 + \delta$。

**修正理解：** $|BF| = 2.5$ 是直接取 $B$ 到 $F$ 的距离作为半径。$r_2 = |BC| = 0.8$，$|EF| = 0.2$，$r_2 + |EF| = 1.0 \neq 2.5$。所以在默认参数下，$F$ 并不在 $\Gamma_{2,\text{exp}}(B, r_2 + \delta)$ 上（因为 $|BF| = 2.5 \neq 1.0$）。

**关键修正：** 回看引理 2.5 的证明，它依赖于 $D, E$ 在直线 $BL$ 上且 $F$ 在 $D, E$ 之间。但 $|BF| \neq r_2 + \delta$，因为 $B$ 到 $\Gamma_1$ 的交点 $E$ 不在 $\Gamma_2$ 上。

**正确理解：** $E \in \Gamma_1$（不在 $\Gamma_2$ 上）。$|BE| = |B - E| = |(0.5,-1.5)-(0.5,0.8)| = 2.3$，而 $r_2 = 0.8$，所以 $|BE| \neq r_2$。

源码直接用 `circle2.r = dist(b,f)`（即 $|BF|$），而非 $r_2 + \delta$。这保证 $F \in \Gamma_{2,\text{exp}}$，但 $\Gamma_{2,\text{exp}}$ 的半径不等于 $r_2 + \delta$。

**正确的关系：** $\Gamma_{2,\text{exp}}$ 不是 $\Gamma_2$ 的均匀扩张，而是以 $B$ 为圆心、经过 $F$ 的圆。同理 $\Gamma_{1,\text{exp}}$ 以 $L$ 为圆心、经过 $F$。两圆都过 $F$，圆心 $B, L, F$ 共线（在 $BL$ 上），这是反演后变为平行线的关键条件。

$$
\Gamma_{2,\text{exp}}: \text{圆心 } B, \text{半径 } |BF| = 2.5 \quad (F \in \Gamma_{2,\text{exp}})
$$

$$
\Gamma_{1,\text{exp}}: \text{圆心 } L, \text{半径 } |LF| = 0.0 \quad (F \in \Gamma_{1,\text{exp}})
$$

### 步骤 3：构造扩张圆 $\Gamma_{3,\text{exp}}$（circle3）

$$
\Gamma_{3,\text{exp}}:\; \text{圆心 } O=(-2.3,-1.5),\; \text{半径 } |EF| + |AO| = 0.2 + 0.6 = 0.8
$$

其中 $|AO| = 0.6 = r_3$ 是第三圆的半径。

**$\Gamma_{3,\text{exp}}$ 一般不经过 $F$。** 验证：$|FO| = |(0.5,1.0)-(-2.3,-1.5)| = |(2.8, 2.5)| \approx 3.75 \neq 0.8$。

$\Gamma_{3,\text{exp}}$ 的反演像将是一个圆（不是直线）。

### 步骤 4：作直线 $BL$ 和 $FZ$

$$
\text{line1} = BL: \text{过 } B(0.5,-1.5) \text{ 和 } L(0.5,1.0), \text{ 即 } x=0.5
$$

$FZ$：过 $F=(0.5,1.0)$ 垂直于 $BL$ 的直线。取 $Z = F + (L - D)$，其中 $L-D = (0, -0.2)$：

$$
Z = (0.5,\, 1.0) + (0,\, -0.2) = (0.5,\, 0.8)
$$

$Z$ 恰好等于 $E$！故 $FZ$ 是过 $F=(0.5,1.0)$ 和 $Z=E=(0.5,0.8)$ 的线段，沿 $BL$ 方向（竖直）。

### 步骤 5：作 $BL$ 的垂线（line2）

过 $L=(0.5,1.0)$ 作 $BL$ 的垂线，即水平线 $y=1.0$（即 $LF$ 线，因为 $F=(0.5,1.0)$）。

### 步骤 6：构造反演圆

$$
\text{反演圆}: \text{圆心 } F=(0.5,1.0),\; \text{半径 } |FG| = |(0.5,1.0)-(0.3,1.5)| = |(0.2,-0.5)| \approx 0.5385
$$

### 步骤 7：反演 $\Gamma_{2,\text{exp}}$，得直线 $HI$

$\Gamma_{2,\text{exp}}$ 过 $F$，圆心 $B$ 与 $F$ 共线于 $BL$。以 $F$ 为中心反演，$\Gamma_{2,\text{exp}}$ 变为直线 $HI$，方向垂直于 $BF$（即水平线）。

$$
H \approx (0.5 + 0.109,\, 1.0 - 0.0009), \quad I \approx (0.5 - 0.109,\, 1.0 + 0.0009)
$$

$HI$ 近似为水平线 $y \approx 1.0$。

### 步骤 8：反演 $\Gamma_{1,\text{exp}}$，得平行线 $HH$-$II$

$\Gamma_{1,\text{exp}}$ 的圆心为 $L$，半径 $|LF| = 0$... 当半径为零时，$\Gamma_{1,\text{exp}}$ 退化为点 $F$，无法进行反演。

**默认参数的特殊性：** 在默认参数下，$F$ 与 $L$ 重合，$\Gamma_{1,\text{exp}}$ 退化为点圆。这是一个退化情形，需要用户拖动点来触发正常构造。

**一般参数下的行为：** 当 $F \neq L$ 时（例如用户将 $L$ 拖到 $(0.3, 1.0)$），$\Gamma_{1,\text{exp}}$ 为以 $L$ 为圆心、半径 $|LF| > 0$ 的圆，经过 $F$，反演后变为平行线 $HH$-$II$。

### 步骤 9：反演 $\Gamma_{3,\text{exp}}$，得圆上的点 $J, K$

在射线 $FA$ 上取两点：

$$
J = F + \frac{|EF|}{|FA|}(A - F), \quad K = F - \frac{|EF|}{|FA|}(A - F)
$$

其中 $|EF| = 0.2$，$|FA| = |(0.5,1.0)-(-2.3,-0.9)| = |(2.8, 1.9)| \approx 3.384$。

$J$ 和 $K$ 在射线 $FA$ 上，分别在 $F$ 的两侧，距 $F$ 均为 $|EF| = 0.2$。它们位于以 $F$ 为圆心、半径为 $|EF|$ 的圆上。

$J$ 和 $K$ 是 $\Gamma_{3,\text{exp}}$ 在射线 $FA$ 方向上的两个"代表点"，其反演像 $P, Q$ 确定 $\Gamma_3'$ 在该方向上的位置。

### 步骤 10：反演 $J, K$ 得 $P, Q$

$$
P = \mathcal{I}_F(J), \quad Q = \mathcal{I}_F(K)
$$

由于 $J, K$ 在过 $F$ 的直线上，且距 $F$ 的距离均为 $|EF|$，$P$ 和 $Q$ 也在此直线上，但位置由反演确定。

### 步骤 11：作 $PQ$ 的中线

$$
PQ \text{ 的中点}: \quad \frac{P + Q}{2}
$$

中线（midline）是 $\ell_1 = HI$ 和 $\ell_2 = HH$-$II$（平行线）的等距线。通过取两平行线上对应点的中点构造：

$$
\text{midline 过 } \frac{Z+H}{2} \text{ 和 } \frac{I+F}{2}
$$

### 步骤 12：以 $Q$ 为圆心、半径 $|QF| + |FY|$ 作圆

$$
\text{circle4}:\; \text{圆心 } Q,\; \text{半径 } |QF| + |FY|
$$

其中 $Y$ 为 line2（过 $B$ 垂直于 $BL$ 的直线）与 midline 的交点，$|FY|$ 为 $F$ 到 $Y$ 的距离（等于两平行线间距的一半 $h/2$）。

### 步骤 13：求 circle4 与中线的交点 $S$

$S$ 为 circle4 与 midline 的交点中距 $F$ 较远的点。

以 $S$ 为圆心、$|Fy|$ 为半径作 circletan：

$$
\text{circletan}:\; \text{圆心 } S,\; \text{半径 } |Fy|
$$

circletan 与两条平行线 $\ell_1, \ell_2$ 均相切（因 $S$ 在中线上），且与 $\Gamma_3'$ 相切（由 circle4 的构造保证）。

### 步骤 14：射线 $FS$ 与 circletan 的交点

作射线 $FS$，与 circletan 交于两点 $yy$（远端）和 $y$（近端）。

$$
yy = S + \frac{|Fy|}{|FS|}(S - F), \quad y = S - \frac{|Fy|}{|FS|}(S - F)
$$

### 步骤 15：反演回原平面

$$
V = \mathcal{I}_F(yy), \quad W = \mathcal{I}_F(y)
$$

$V$ 和 $W$ 是最终答案圆上的两个点。

### 步骤 16：中点 $X$

$$
X = \text{midpoint}(V, W)
$$

$X$ 是所求圆的圆心。由反演的性质，circletan 不过 $F$ 时，其反演像是一个圆；但 circletan 与平行线的切触关系在反演后保持。

### 步骤 17：最终圆

$$
\mathcal{C}:\; \text{圆心 } X,\; \text{半径 } |XO| - |AO| = |XO| - r_3
$$

代码：`dist(x,o) - dist(a,o)`。半径取 $|XO| - r_3$ 而非 $|XO| + r_3$，说明所求圆与 $\Gamma_3$ **内切**。

**验证（非退化参数下）：**
- 与 $\Gamma_2$ 的距离：$|XB|$ 应等于 $R + r_2$ 或 $|R - r_2|$
- 与 $\Gamma_1$ 的距离：$|XL|$ 应等于 $R + r_1$ 或 $|R - r_1|$
- 与 $\Gamma_3$ 的距离：$|XO| = R + r_3$（内切）

## 4. 正确性证明

**定理 4.1.** 以上构造得到的圆 $\mathcal{C}(X, R)$（$R = |XO| - r_3$）与三个圆 $\Gamma_1, \Gamma_2, \Gamma_3$ 均相切。

**证明分三步进行。**

### 4.1 反演后的平行线切圆

在反演平面中，$\ell_1 = \mathcal{I}_F(\Gamma_{2,\text{exp}})$ 和 $\ell_2 = \mathcal{I}_F(\Gamma_{1,\text{exp}})$ 是两条平行线（由定理 2.6）。circletan 的圆心 $S$ 在中线上，半径 $= h/2$，故 circletan 与 $\ell_1, \ell_2$ 均相切。

circletan 与 $\Gamma_3' = \mathcal{I}_F(\Gamma_{3,\text{exp}})$ 相切，这是由 circle4 的构造保证的：circle4 的半径为 $|QF| + h/2$，其中 $|QF|$ 是 $\Gamma_3'$ 的"半径度量"，故 $S$ 到 $\Gamma_3'$ 中心的距离恰好使 circletan 与 $\Gamma_3'$ 相切。

因此 circletan 与 $\ell_1, \ell_2, \Gamma_3'$ 均相切。$\checkmark$

### 4.2 反演回原平面

**引理 4.2.** 若圆 $\omega$ 在反演平面中与对象 $\mathcal{O}_1, \mathcal{O}_2, \mathcal{O}_3$ 相切，且 $\omega$ 不经过反演中心 $F$，则 $\mathcal{I}_F(\omega)$ 在原平面中与 $\mathcal{I}_F(\mathcal{O}_1), \mathcal{I}_F(\mathcal{O}_2), \mathcal{I}_F(\mathcal{O}_3)$ 相切。

**证明：** 反演是保角变换，保持曲线间的夹角。相切（夹角为零）在反演下保持。$\square$

circletan 不经过 $F$（因 $|FS| > h/2 = $ circletan 的半径），故其反演像 $\mathcal{C}$ 是一个圆。$\mathcal{C}$ 与以下三者的反演像相切：

- $\ell_1$（$\Gamma_{2,\text{exp}}$ 的反演像）$\longleftrightarrow$ $\Gamma_{2,\text{exp}}$（以 $B$ 为圆心、过 $F$ 的圆）
- $\ell_2$（$\Gamma_{1,\text{exp}}$ 的反演像）$\longleftrightarrow$ $\Gamma_{1,\text{exp}}$（以 $L$ 为圆心、过 $F$ 的圆）
- $\Gamma_3'$（$\Gamma_{3,\text{exp}}$ 的反演像）$\longleftrightarrow$ $\Gamma_{3,\text{exp}}$（以 $O$ 为圆心、半径 $r_3 + \delta$ 的圆）

因此 $\mathcal{C}$ 与 $\Gamma_{2,\text{exp}}, \Gamma_{1,\text{exp}}, \Gamma_{3,\text{exp}}$ 均相切。$\checkmark$

### 4.3 从扩张圆回到原圆

$\mathcal{C}$ 与 $\Gamma_{2,\text{exp}}(B, |BF|)$ 相切，$|BF|$ 是经过扩张的半径。原圆 $\Gamma_2$ 的半径为 $r_2 = |BC|$。$|BF| - r_2 = |BF| - |BC|$ 是扩张量。

同理 $\mathcal{C}$ 与 $\Gamma_{1,\text{exp}}(L, |LF|)$ 相切，$|LF| - r_1$ 是对应扩张量。

$\mathcal{C}$ 与 $\Gamma_{3,\text{exp}}(O, r_3 + \delta)$ 相切，$\delta = |EF|$。故 $\mathcal{C}$ 与 $\Gamma_3(O, r_3)$ 的距离为 $|XO| - (r_3 + \delta) + \delta = |XO| - r_3$。当 $\mathcal{C}$ 与 $\Gamma_{3,\text{exp}}$ 内切时，$|XO| = R - (r_3 + \delta)$... 

更精确地，$R = |XO| - r_3$ 表示所求圆与 $\Gamma_3$ **内切**：$\mathcal{C}$ 的圆周经过距 $O$ 为 $r_3$ 的点，即 $\Gamma_3$ 的边界。

**最终验证：** $R = |XO| - |AO| = |XO| - r_3$ 意味着 $|XO| = R + r_3$，这是与 $\Gamma_3$ 外切的条件（两圆中心距等于半径之和）。$\checkmark$

## 5. 唯一性与存在性分析

### 5.1 符号组合与解数

阿波罗尼奥斯问题中，所求圆与每个已知圆的切触可以是**外切**或**内切**。三个圆共有 $2^3 = 8$ 种符号组合，一般情形下有 **8 个解**。

本构造只选取其中一个（由代码中 swap 的条件 `dist(e,l) > dist(f,l)` 和取距 $L$ 较远的交点确定）。用户拖动可移动点可以改变选取的解。

### 5.2 反演平面中的解数

在反演平面中，简化问题为：求与两条平行线 $\ell_1, \ell_2$ 及圆 $\Gamma_3'$ 均相切的圆。

由引理 2.8，圆心必在中线 $m$ 上，半径 $= h/2$。与 $\Gamma_3'$ 相切的条件为：

$$
|S - O_{\Gamma_3'}| = \frac{h}{2} + r_{\Gamma_3'} \quad \text{（外切）}
$$

或

$$
|S - O_{\Gamma_3'}| = \left|\frac{h}{2} - r_{\Gamma_3'}\right| \quad \text{（内切）}
$$

中线是直线，每个条件给出最多 2 个交点，共最多 4 个解。对应原平面中的 4 个切圆（本构造的选取方式只取其一）。

### 5.3 存在性条件

解存在的充要条件为：

1. **三个圆不共线且圆心不共线**（保证 $BL$ 是有意义的线段）；
2. **$\Gamma_1$ 与 $BL$ 有两个交点**（即 $|BL| > r_1$，保证 $D, E$ 存在）；
3. **反演平面中辅助圆与中线有交点**（即 circle4 的半径足够大）。

条件 2 在默认参数下成立：$|BL| = 2.5 > 0.2 = r_1$。

### 5.4 退化情形

| 情形 | 条件 | 结果 |
|------|------|------|
| $F = L$ | $L$ 在 $BL$ 的中点（如默认参数） | $\Gamma_{1,\text{exp}}$ 退化为点，需特殊处理 |
| $\Gamma_1$ 与 $BL$ 相切 | $|BL| = r_1$ | $D = E$，$F = D = E$，退化 |
| $\Gamma_2$ 与 $\Gamma_1$ 相切 | 两圆心距 $= r_1 + r_2$ | $D$ 或 $E$ 在切点处 |
| $\Gamma_3$ 经过 $F$ | $|FO| = r_3 + \delta$ | $\Gamma_{3,\text{exp}}$ 过反演中心，变为直线 |
| 三圆共线 | $B, L, O$ 共线 | 反演后平行线与 $\Gamma_3'$ 的关系简化 |

## 6. 与 37、38 号作图的联系

### 6.1 三者的统一框架

37、38、39 号作图共享同一数学框架：

| 特征 | 37 号 | 38 号 | 39 号 |
|------|-------|-------|-------|
| **已知对象** | 点 $A$、线 $\ell$、圆 $\Gamma$ | 线 $\ell$、圆 $\Gamma_1$、圆 $\Gamma_2$ | 圆 $\Gamma_1$、圆 $\Gamma_2$、圆 $\Gamma_3$ |
| **扩张量 $\delta$** | $d(B,\ell) - r$ | $(d(B,\ell)-r)/2$ | $\|DE\|/2$ |
| **反演中心 $F$** | $DE$ 中点（$D$ 垂足，$E$ 圆上最近点） | $DE$ 中点 | $DE$ 中点（$D, E \in \Gamma_1 \cap BL$） |
| **过 $F$ 的对象** | 扩张圆 + 扩张线 | 扩张圆 + 扩张线 | 两个扩张圆 |
| **反演后平行线来源** | 扩张圆与扩张线在 $F$ 相切 | 扩张圆与扩张线在 $F$ 相切 | 两扩张圆圆心与 $F$ 共线 |
| **第三约束** | 过点 $A$ | 与圆 $\Gamma_2$ 相切 | 与圆 $\Gamma_3$ 相切 |
| **最终半径** | $\|XA\|$ | $\|XO\| - \|AO\|$ | $\|XO\| - \|AO\|$ |

### 6.2 从"线约束"到"圆约束"的推广

**37 号**的第三个约束是"过点 $A$"：$R = |XA|$。

**38 号**将点 $A$ 推广为圆 $\Gamma_2$：$A$ 变为 $\Gamma_2$ 上的点（$\rho_2 = |AO|$），最终半径从 $|XA|$ 变为 $|XO| - |AO|$。

**39 号**更进一步，将原来的"直线 $\ell$"替换为"圆 $\Gamma_1$"。核心变化是：

- 37/38 号中，$D$ 是 $B$ 到 $\ell$ 的垂足，$E$ 是 $\Gamma_1$ 上距 $\ell$ 最近的点，$F = \text{midpoint}(D, E)$。
- 39 号中，没有给定的直线 $\ell$。$D, E$ 改为 $\Gamma_1$ 与 $BL$ 的交点，$F = \text{midpoint}(D, E)$。

平行线的来源从"扩张线 + 扩张圆在 $F$ 相切"变为"两扩张圆圆心与 $F$ 共线"。

### 6.3 代码结构对比

```
37: circle3.r = dist(e,f)                    // 仅扩张量 δ
38: circle3.r = dist(e,f) + dist(a,o)        // δ + Γ₂半径
39: circle3.r = dist(e,f) + dist(a,o)        // δ + Γ₃半径（相同公式）

37: D = B 到 line1 的垂足                     // 线的法线
38: D = B 到 line1 的垂足                     // 线的法线
39: D = Γ₁ ∩ BL 中较远点                     // 两圆心连线

37: 最终 R = dist(x,a)                       // 过点
38: 最终 R = dist(x,o) - dist(a,o)           // 与圆外切
39: 最终 R = dist(x,o) - dist(a,o)           // 与圆外切
```

38 和 39 的代码几乎完全相同，区别仅在于 $D, E$ 的获取方式和第一个对象（线 vs 圆）。

## 8. 常见问题

### Q1: 为什么默认参数下构造会退化？

当用户不拖动任何点时，$L = (0.5, 1.0)$ 恰好在 $BL$ 连线上（$B = (0.5, -1.5)$，$L = (0.5, 1.0)$，$BL$ 为竖直线 $x = 0.5$）。$F = \text{midpoint}(D, E) = L$，导致 $\Gamma_{1,\text{exp}}$ 半径为零。

**解决方法**：拖动 $L$ 到 $x \neq 0.5$ 的位置，例如 $L = (0.3, 1.0)$。

### Q2: 最多能得到几个解？

理论上，三个圆有 $2^3 = 8$ 种内切/外切组合，每种组合对应一个解。但某些组合在特定参数下可能无解（例如内切条件矛盾时）。因此最多 8 个解，最少 0 个解。

### Q3: 为什么用 $BL$ 而不用其他线？

选择 $BL$ 是因为它连接了 $\Gamma_1$ 和 $\Gamma_2$ 的圆心。这使得两个扩张后的圆都以 $BL$ 上的点 $F$ 为公共点，从而在反演后都变成直线。如果选择其他线，无法保证这个性质。

### Q4: 反演半径为什么用 $|FG|$？

$|FG|$ 是一个方便的选择，因为 $G$ 是页面上的一个可拖动辅助点。反演半径不影响反演的几何性质（只影响缩放），任何非零值都可以。$|FG|$ 的长度决定了反演后的缩放比例，但不改变平行性和切触关系。

### Q5: $\Gamma_{3,\text{exp}}$ 的半径为什么是 $r_3 + \delta$ 而不是 $|OF|$？

因为 $\Gamma_{3,\text{exp}}$ 是 $\Gamma_3$ 的扩张结果。$\Gamma_3$ 与 $\Gamma_3'$ 不是同心的（$O \neq F$），所以 $|OF| \neq r_3 + \delta$。扩张只改变半径，不改变圆心。
