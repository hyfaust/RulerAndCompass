# 尺规作图 34：过点与角相切的圆 — 数学分析

## 1. 问题描述

给定一个角 $\angle BAC$（顶点为 $A$，两条射线分别为 $\overrightarrow{AB}$ 和 $\overrightarrow{AC}$）以及角内一点 $D$，要求用尺规作图构造一个圆，使得该圆：

1. **经过点 $D$**；
2. **与角的两条射线均相切**。

默认坐标设定：

$$A = (-2,\, 1),\quad B = (2.7,\, 1),\quad C = (0,\, -2.5),\quad D = (1,\, -0.2)$$

---

## 2. 数学模型

### 2.1 坐标框架

以 $A$ 为原点建立局部坐标系，令 $\overrightarrow{AB}$ 为 $x$ 轴正方向。在此框架下：

- $\overrightarrow{AB}$ 的单位方向向量：$\mathbf{u}_{AB} = (1,\, 0)$
- $\overrightarrow{AC}$ 的单位方向向量：$\mathbf{u}_{AC} = (\cos\alpha,\, -\sin\alpha)$，其中 $\alpha = \angle BAC$
- 角平分线的单位方向向量：$\mathbf{u}_b = \dfrac{\mathbf{u}_{AB} + \mathbf{u}_{AC}}{|\mathbf{u}_{AB} + \mathbf{u}_{AC}|}$

### 2.2 角度计算

$$\cos\theta = \mathbf{u}_{AB} \cdot \mathbf{u}_{AC} = 1 \times 0.4961 + 0 \times (-0.8682) = 0.4961$$

$$\theta = \arccos(0.4961) \approx 60.26°$$

半角：

$$\beta = \frac{\theta}{2} \approx 30.13°,\quad \cos\beta \approx 0.8649,\quad \sin\beta \approx 0.5019,\quad \tan\beta \approx 0.5803$$

角平分线方向：

$$\mathbf{u}_b = (0.8649,\, -0.5019)$$

### 2.3 核心方程

设所求圆的圆心 $O$ 在角平分线上，距 $A$ 的距离为 $t$，即 $O = A + t\,\mathbf{u}_b$。圆的半径为 $r$。

**条件一（与两射线相切）**：圆心到任一射线的距离等于半径：

$$r = t \sin\beta$$

**条件二（经过点 $D$）**：

$$|OD| = r \quad\Longrightarrow\quad |O - D| = t\sin\beta$$

设 $D$ 在角平分线方向上的投影坐标为 $d_x = (D - A) \cdot \mathbf{u}_b$，则在以角平分线为 $x$ 轴的旋转坐标系中，$D$ 的坐标为 $(d_x,\, d_y)$，其中 $d_y$ 为垂直于角平分线的分量。条件二展开为：

$$(t - d_x)^2 + d_y^2 = t^2 \sin^2\beta$$

整理得关于 $t$ 的二次方程：

$$\cos^2\!\beta \cdot t^2 - 2d_x \cdot t + |D - A|^2 = 0 \tag{1}$$

### 2.4 求解公式

由二次方程公式：

$$t = \frac{d_x \pm \sqrt{d_x^2 - \cos^2\!\beta \cdot |D-A|^2}}{\cos^2\!\beta} \tag{2}$$

取较小解（减号），得到**靠近顶点 $A$ 的圆**：

$$t = \frac{d_x - \sqrt{d_x^2 - \cos^2\!\beta \cdot |D-A|^2}}{\cos^2\!\beta}$$

### 2.5 HTML 原理说明中的等价形式

源文件中的原理说明使用了另一种等价的参数化。在以 $A$ 为原点、$\overrightarrow{AB}$ 为 $x$ 轴的坐标系中，设角平分线斜率为 $m = \tan\beta$，$D = (a,\, b)$，圆心为 $(x,\, mx)$，则：

$$mx = \sqrt{(x-a)^2 + (mx-b)^2}$$

解得：

$$x = (a + mb) - \sqrt{(a+mb)^2 - (a^2+b^2)} \tag{3}$$

其中各分量的几何意义为：

| 符号 | 几何含义 | 构造对应 |
|------|---------|---------|
| $b$ | $D$ 到 $\overrightarrow{AB}$ 的垂直距离 | $|DE|$ |
| $mb$ | $\|DE\| \cdot \tan\beta$ | $\|FG\|$ |
| $a + mb$ | 沿 $\overrightarrow{AB}$ 从 $A$ 到辅助点 $H$ 的距离 | $\|AH\|$ |
| $\sqrt{(a+mb)^2-(a^2+b^2)}$ | 由勾股定理得到的修正量 | $\|DI\|$ |
| $x$ | 圆心在 $x$ 轴上的投影 | $\|AJ\|$ |

## 3. 构造步骤详细推导

以下逐步分析源文件 `34-CircleAnglePoint.html` 中的 11 个构造步骤，说明每一步的几何目的和代数含义。

### 步骤 1：过 $D$ 作 $AB$ 的垂线，得垂足 $E$

过 $D$ 作直线 $L_3$ 垂直于射线 $AB$，$L_3$ 与 $AB$ 的交点为 $E$。

$$E = (1,\, 1)$$

$E$ 是 $D$ 在直线 $AB$ 上的垂足，$|DE|$ 即为点 $D$ 到射线 $AB$ 的垂直距离：

$$|DE| = |D_y - A_y| = |-0.2 - 1| = 1.2$$

在公式 (3) 的框架中，$|DE| = |b| = 1.2$。

### 步骤 2：以 $A$ 为圆心、$|DE|$ 为半径作圆 $c_1$

$$c_1:\; \text{圆心} A(-2,1),\; \text{半径}\; R_1 = |DE| = 1.2$$

此圆用于在两条射线上截取等于 $|DE|$ 的线段，是长度转移的基本工具。

### 步骤 3：$c_1$ 与 $AB$ 的交点 $F$

圆 $c_1$ 与直线 $AB$（$y=1$）的交点满足 $(x+2)^2 = 1.44$，解得 $x = -0.8$ 或 $x = -3.2$。取离 $B$ 较近的点：

$$F = (-0.8,\, 1)$$

因此 $|AF| = |DE| = 1.2$，即 $F$ 是将 $|DE|$ 的长度转移到射线 $AB$ 上的结果。

### 步骤 4：过 $F$ 作 $AB$ 的垂线 $L_4$

$$L_4:\; x = -0.8$$

$L_4$ 是过 $F$ 垂直于 $AB$ 的直线，后续用于与角平分线相交确定关键距离。

### 步骤 5：$c_1$ 与射线 $AC$ 的交点 $P$

圆 $c_1$ 与射线 $AC$ 的交点中，取距 $A$ 为 $|DE|$ 且在 $AC$ 方向上的点：

$$P = A + |DE| \cdot \mathbf{u}_{AC} = (-1.4046,\, -0.0419)$$

$|AP| = |DE| = 1.2$，与 $|AF|$ 相等。

### 步骤 6：$F$ 与 $P$ 的中点 $Q$

$$Q = \left(\frac{F_x + P_x}{2},\, \frac{F_y + P_y}{2}\right) = (-1.1023,\, 0.4791)$$

**关键性质**：由于 $|AF| = |AP| = |DE|$，三角形 $\triangle AFP$ 是以 $A$ 为顶点的等腰三角形。由等腰三角形性质，顶点 $A$ 到底边中点 $Q$ 的连线 $AQ$ 正是 $\angle FAP$ 的角平分线，而 $\angle FAP = \angle BAC$（因为 $F$ 在 $AB$ 上，$P$ 在 $AC$ 上）。因此：

$$\overrightarrow{AQ} \;\text{就是}\; \angle BAC \;\text{的角平分线方向}$$

验证：$\overrightarrow{AQ}$ 的单位向量为 $(0.8649,\, -0.5019)$，与 $\mathbf{u}_b$ 完全一致。

### 步骤 7：角平分线 $L_5 = A \to Q$

$$L_5:\; \text{从}\; A(-2,1)\; \text{出发，方向}\; (0.8977,\, -0.5209)$$

### 步骤 8：$G = L_4 \cap L_5$

$L_4$（$x = -0.8$）与角平分线 $L_5$ 的交点：

$$G = (-0.8,\, 0.3036)$$

$G$ 是角平分线上与 $F$ 具有相同 $AB$ 方向坐标的点。

### 步骤 9：以 $E$ 为圆心、$|FG|$ 为半径作圆 $c_2$

$$|FG| = |F_y - G_y| = 1 - 0.3036 = 0.6964$$

在公式 (3) 的框架中，$|FG| = mb = |DE| \cdot \tan\beta = 1.2 \times 0.5803 = 0.6964$。

这一步通过几何构造计算出了 $|DE| \cdot \tan\beta$，无需显式使用三角函数。

### 步骤 10：$H$ 为 $c_2$ 与 $AB$ 的交点

$$c_2:\; \text{圆心}\; E(1,1),\; \text{半径}\; 0.6964$$

交点中取离 $B$ 较远的点：$H = (1.6964,\, 1)$。

$$|AH| = |A_x - H_x| = 3.6964$$

代数含义：$|AH| = |AE| + |EH| = a + mb$，对应公式 (3) 中的 $(a + mb)$。

### 步骤 11：作线段 $AD$，过 $D$ 作 $AD$ 的垂线 $L_6$

$AD$ 方向：$(D - A) = (3,\, -1.2)$

$L_6$ 过 $D$ 垂直于 $AD$，方向为 $(1.2,\, 3)$。

### 步骤 12：以 $A$ 为圆心、$|AH|$ 为半径作圆 $c_3$，交 $L_6$ 于 $I$

$$c_3:\; \text{圆心}\; A(-2,1),\; \text{半径}\; |AH| = 3.6964$$

$I$ 为 $c_3$ 与 $L_6$ 的交点中 $y$ 坐标较大者：

$$I = (1.6668,\, 1.4669)$$

由勾股定理（$L_6 \perp AD$，$I$ 在以 $A$ 为圆心的圆上）：

$$|DI|^2 = |AI|^2 - |AD|^2 = |AH|^2 - |AD|^2$$

$$|DI| = \sqrt{3.6964^2 - (\sqrt{10.44})^2} = \sqrt{13.663 - 10.44} = \sqrt{3.223} = 1.7953$$

代数含义：$|DI| = \sqrt{(a+mb)^2 - (a^2+b^2)}$，对应公式 (3) 中的根号项。

### 步骤 13：以 $H$ 为圆心、$|DI|$ 为半径作圆 $c_4$，交 $AB$ 于 $J$

$$c_4:\; \text{圆心}\; H(1.6964,\, 1),\; \text{半径}\; |DI| = 1.7953$$

交点中取离 $A$ 较近的点：

$$J = (-0.0990,\, 1)$$

$$|AJ| = |AH| - |DI| = 3.6964 - 1.7953 = 1.9010$$

代数含义：$|AJ| = (a+mb) - \sqrt{(a+mb)^2-(a^2+b^2)} = x$，这正是公式 (3) 的解。

### 步骤 14：过 $J$ 作 $AB$ 的垂线 $L_7$，与 $L_5$ 交于 $K$

$L_7$ 垂直于 $AB$ 且过 $J$：$x = -0.0990$

$K = L_5 \cap L_7$：

$$K = (-0.0990,\, -0.1032)$$

$K$ 在角平分线上，且其在 $AB$ 方向上的投影恰为 $|AJ| = x$，因此 $K$ 的角平分线坐标为：

$$t = \frac{|AJ|}{\cos\beta} = \frac{1.9010}{0.8649} = 2.1980$$

### 步骤 15：以 $K$ 为圆心、过 $D$ 作圆

$$r = |KD| = \sqrt{(1+0.0990)^2 + (-0.2+0.1032)^2} = 1.1032$$

**最终结果**：以 $K(-0.0990,\, -0.1032)$ 为圆心、$r = 1.1032$ 为半径的圆即为所求。

## 4. 正确性证明

**定理**：上述构造得到的圆经过点 $D$，且与射线 $\overrightarrow{AB}$ 和 $\overrightarrow{AC}$ 均相切。

**证明**：

需验证以下三个等式：

**(i) 圆经过 $D$**：$|KD| = r$。由构造直接得出（$r$ 就是以 $|KD|$ 为半径画的圆）。

**(ii) 圆心到 $AB$ 的距离等于半径**：

由于 $AB$ 是水平线（$y = 1$），$K = (K_x,\, K_y)$：

$$\text{dist}(K, AB) = |K_y - 1| = |-0.1032 - 1| = 1.1032 = r \quad\checkmark$$

**(iii) 圆心到 $AC$ 的距离等于半径**：

直线 $AC$ 的方程：$3.5x + 2y + 5 = 0$

$$\text{dist}(K, AC) = \frac{|3.5 \times (-0.0990) + 2 \times (-0.1032) + 5|}{\sqrt{3.5^2 + 2^2}} = \frac{4.4473}{4.0311} = 1.1032 = r \quad\checkmark$$

**代数证明（一般情形）**：

设角平分线上的点 $O = A + t\,\mathbf{u}_b$，需证明当 $t$ 取公式 (2) 的值时，$|OD| = t\sin\beta$。

在以角平分线为 $x$ 轴的坐标系中，$O = (t,\, 0)$，$D = (d_x,\, d_y)$。

- 圆心到两射线的距离：$t\sin\beta$（由角平分线性质，到两射线等距）
- 圆心到 $D$ 的距离：$\sqrt{(t-d_x)^2 + d_y^2}$

由公式 (1)：$\cos^2\!\beta \cdot t^2 - 2d_x \cdot t + |D-A|^2 = 0$

即 $t^2(1 - \sin^2\!\beta) - 2d_x t + d_x^2 + d_y^2 = 0$

$t^2 - t^2\sin^2\!\beta - 2d_x t + d_x^2 + d_y^2 = 0$

$(t - d_x)^2 + d_y^2 = t^2 \sin^2\!\beta$

$\sqrt{(t-d_x)^2 + d_y^2} = t\sin\beta$

即 $|OD| = t\sin\beta = r$。$\blacksquare$

**构造正确性的核心逻辑链**：

$$|AJ| = |AH| - |DI| = (a+mb) - \sqrt{(a+mb)^2-(a^2+b^2)} = x$$

$$t = \frac{|AJ|}{\cos\beta} = \frac{x}{\cos\beta}$$

$$K = A + t\,\mathbf{u}_b \quad\Longrightarrow\quad |KD| = t\sin\beta = r$$

每一步都通过尺规作图的合法操作（作垂线、取交点、画圆、取中点）实现了代数公式中对应量的几何构造。

## 5. 唯一性与存在性分析

### 5.1 判别式分析

方程 (1) 的判别式为：

$$\Delta = 4d_x^2 - 4\cos^2\!\beta \cdot |D-A|^2$$

令 $\alpha$ 为 $AD$ 与角平分线的夹角，则 $d_x = |D-A|\cos\alpha$，代入得：

$$\Delta = 4|D-A|^2(\cos^2\!\alpha - \cos^2\!\beta)$$

### 5.2 存在条件

$\Delta \geq 0$ 要求 $\cos^2\!\alpha \geq \cos^2\!\beta$，即 $|\alpha| \leq \beta$。

**几何解释**：点 $D$ 必须位于角 $\angle BAC$ 的内部（含边界）。当 $D$ 在角内时，$AD$ 与角平分线的夹角不超过半角 $\beta$，判别式非负。

### 5.3 解的个数

| 条件 | 判别式 | 解的个数 | 几何意义 |
|------|--------|---------|---------|
| $D$ 在角内部（$|\alpha| < \beta$） | $\Delta > 0$ | **2 个** | 一大一小两个圆 |
| $D$ 在射线上（$|\alpha| = \beta$） | $\Delta = 0$ | **1 个** | 圆与该射线切于 $D$ |
| $D$ 在角外部（$|\alpha| > \beta$） | $\Delta < 0$ | **0 个** | 无解 |

### 5.4 两个解的几何意义

对于默认坐标，存在两个解：

| | 圆心 $K$ | 半径 $r$ | 位置特征 |
|--|----------|---------|---------|
| 解 1（取 $-$） | $(-0.099,\, -0.103)$ | $1.103$ | 靠近顶点 $A$ |
| 解 2（取 $+$） | $(3.492,\, -2.187)$ | $3.187$ | 远离顶点 $A$ |

**本构造取减号解**（靠近顶点 $A$ 的较小圆），这是尺规作图中最常见的选择。

### 5.5 退化情形

- 若 $D = A$，则 $|D-A| = 0$，方程 (1) 变为 $\cos^2\!\beta \cdot t^2 = 0$，得 $t = 0$，即退化解（半径为零的点圆）。
- 若 $D$ 在角平分线上（$d_y = 0$），则两个解关于 $D$ 对称，其中一个圆在 $D$ 处与角平分线相切。

## 附录：构造流程总结

```
给定: 角 ∠BAC, 角内一点 D

1. 过 D 作 AB 的垂线 → 垂足 E, 得 |DE| = 点到射线的距离
2. 以 A 为圆心、|DE| 为半径作圆 → 长度转移工具
3. 圆与 AB 交于 F → |AF| = |DE|
4. 过 F 作 AB 的垂线 L₄
5. 圆与 AC 交于 P → |AP| = |DE|
6. 取 FP 中点 Q → AQ 为角平分线 L₅
7. L₄ ∩ L₅ = G → |FG| = |DE|·tan(β)
8. 以 E 为圆心、|FG| 为半径作圆, 交 AB 于 H → |AH| = a + mb
9. 过 D 作 AD 的垂线 L₆
10. 以 A 为圆心、|AH| 为半径作圆, 交 L₆ 于 I → |DI| = √((a+mb)²-(a²+b²))
11. 以 H 为圆心、|DI| 为半径作圆, 交 AB 于 J → |AJ| = (a+mb)-√(...) = x
12. 过 J 作 AB 的垂线 L₇, 与角平分线 L₅ 交于 K → 圆心
13. 以 K 为圆心、过 D 作圆 → 所求圆
```
